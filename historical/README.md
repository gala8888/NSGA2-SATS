# Archived experiment results

These files contain historical results associated with the manuscript and supplementary material.

| Directory | Contents |
|---|---|
| `main/pareto_fronts` | Seven instances × 30 final Pareto fronts |
| `main/hv_histories` | HV histories and run summaries |
| `main/NSGA2-SATS_overall_stats.csv` | Main experiment HV statistics |
| `metrics` | HV, IGD, and Spread comparison tables |
| `ablation` | Five-variant HV summaries |
| `large` | Large-scale experiment summaries |

[source-manifest.json](source-manifest.json) records source paths and file checksums. New experiments save their results to the output directory selected at runtime.
